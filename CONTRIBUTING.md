# Contributing

This repo is maintained by Payroc Sales Engineering. It is public for transparency and easy plugin installs.

- **Team members:** branch from `main` (`feature/...` or `fix/...`), open a pull request, and get one approval from a code owner. Direct pushes to `main` are blocked.
- **Everyone else:** you are welcome to open an issue or a pull request from a fork. We review these on a best-effort basis and may decline changes that don't fit the plugin's scope.
- **Never commit** API keys, tokens, secrets, customer or partner data, or internal links. See [docs/security_payroc.md](docs/security_payroc.md).
- **Security issues:** please don't open a public issue. Use GitHub's "Report a vulnerability" button on the Security tab.
