# Introduction

Worldnet offers a number of different ways for you to accept cardholder present payments.

Whether using mobile on iOS or Android, a counter top retail space or an unattended kiosk environment, we have you covered!

## ** Websockets

We recommend using our Websockets solution as the best way to integrate to our platform. Check out a simple example in the [Coding 101](doku.php?id=gochip:pos:coding_101) section. if that doesn't work for you the GoChip SDK is available in a number of languages.

To get started, choose the solution that best suites you, either POS or mPOS.

Here’s a small set of environments where each solution could cover:

#### ** POS

Worldnet’s intelligent retail solution, with support for tips and unattended payments, offers a range of possibilities:

- Restaurants
- Built in Taxi Solution
- Standard Retail Environment
- Gas Stations
- Unattended Kiosks

Click [here](doku.php?id=gochip:pos:coding_101) to get started with POS development.
