# API Specification - ACH JH

Automated Clearing House (ACH) is an electronic network for financial transactions in the United States. ACH credit transfers include direct deposit, payroll and vendor payments. ACH direct debit transfers include consumer payments on insurance premiums, mortgage loans and other kinds of bills.

The Worldnet Payments system is a secure server-based transaction processing service that will enable your business to authorize and process ACH transactions online in real time. The information needed to process the transactions is sent over a secure, encrypted internet connection.

Once the customer has completed the payment form, the Worldnet Payments server connects with the ACH processor for payment authorization and if the sale is authorized, returns a receipt to the customer. Worldnet Payments settles the transactions automatically and the acquiring bank deposits the funds into your bank account. Worldnet Payments automatically archives sales that are finalized so that you can refer to them at a later date.

This guide provides instructions on how to integrate a website or application into the system and take ACH payments.
