# PayFac

*Open Batch and Closed Batch Reporting for all terminals*

When the Portfolio Administrator access the Admin system they will only view the merchants within its Portfolio.

Select the merchant and the ‘Processing Terminal’ tab, then select ‘Access’

In the access frame, select ‘Reporting’ and in ‘Open Batch’, two tabs are available: **Selected Terminal** and **All Terminals**. Select All Terminals.
