# Receipt

You can find the **RECEIPT** section under **SETTINGS** tab in the Selfcare.

Select **Receipt** from the drop down box to add a receipt disclaimer (currently available for Virtual Terminal).

When data entry is complete, select “**Update Receipt Settings**”.
