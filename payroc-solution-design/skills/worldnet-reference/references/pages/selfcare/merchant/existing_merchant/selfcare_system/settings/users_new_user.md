# Users - New User

User Setup is available only to users with permission to access this feature. It allows merchants to maintain their own users.

To add a new user, click the ‘**New User**’ button on the Users List page - this will open a new page with an empty form:

Sample **Users - New user** window:

The form contains the following fields:

**Username** – username for the user being created

**eMail** – email address of the user being created

**Your Current Password** – your password to verify that you have valid permissions to create new users

**Default Terminal ID** – select box with all merchant terminals, default terminal for the user should be chosen

Before you add a new user you need to give them permissions by clicking on “More Settings”.
