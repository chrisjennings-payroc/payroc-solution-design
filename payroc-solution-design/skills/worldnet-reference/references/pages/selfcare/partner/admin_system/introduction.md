# General Overview

The **Admin System** provides partners with full control of their merchants.

The system allows partners to set up accounts and users, as well as check transactions across all terminals. The System also comes with many additional options and features and can be configured to suit your business requirements.

The Admin System consists of the following:

1. [Merchant Details](https://developers.worldnetpayments.com/partner/admin_system/merchant_details)
1. [Terminal Setup](https://developers.worldnetpayments.com/partner/admin_system/terminal_setup)
1. [User Management](https://developers.worldnetpayments.com/partner/admin_system/users)
